# md-collab native client (PR1 foundation)

Tauri 2 + WKWebView desktop client for md-collab. PR1 ships a **strictly read-only**
foundation: workspace picker, file tree with `{open_count}` badges, CodeMirror 6 viewer,
sidecar thread decorations (high/medium/low confidence), and a minimal right-side
thread panel (Open / Broken / Resolved).

**No mutation paths.** All writes (including broken-anchor relink) land in PR2 via
`mdc` shell-out per `.ai/spec/guidance/frontend/guidance-for-native-client-mvp.md` §6.

## Prerequisites

- macOS 14+ with Xcode Command Line Tools (`xcode-select --install`)
- Rust stable (`rustup default stable`)
- Node 20+ (`nvm install 20`)
- `cargo-tauri` (`cargo install tauri-cli --version "^2.0"`)

## Bootstrap

```bash
# From repo root, install root deps + build core
npm install
npm run build

# In this directory
cd native-client
npm install
npm run sync-core          # mirrors ../dist into vendor/core
npm run build-validator    # generates src/app/generated/sidecar-validator.js
npm run typecheck

# Run the app (Rust + Vite dev)
cargo tauri dev
```

## Cross-frontend conventions honored

- `@pierre/trees@1.0.0-beta.3` (Apache-2.0). Verify with
  `npm view @pierre/trees@1.0.0-beta.3 license`.
- AJV standalone validator (no runtime `eval`); CSP stays `default-src 'self'`.
- Vendored core is gitignored; regenerated by `pre*` hooks on dev/typecheck/build.
- `npm` is used (not `bun`) for parity with `vscode-extension/` and `obsidian-plugin/`.

## What ships in PR1

- Workspace picker + restore-last-workspace

- CodeMirror 6 read-only viewer
- Sidecar thread decorations (gutter + inline) for `high/medium/low`
- Minimal thread panel: Open / Broken / Resolved sections
- Sidecar parse-error mode with "Reveal sidecar in editor" external-repair flow
